DAILYPOST DEMO — PHP + MYSQL + 100 DUMMY STORIES

1. Create a MySQL database on your hosting panel.
2. Import database_demo.sql in phpMyAdmin.
3. Edit config/db.php with your database name, username and password.
4. Upload all files/folders to public_html or htdocs.
5. Open your website.
