# DailyPost

Simple, colorful read-and-write publication website.

Open `index.html` to run the prototype.

Included:
- Read / Write navigation
- Featured, Latest, Most Read, Editor's Picks, Daily Digest
- Colorful responsive design
- Search
- Story submission
- Browser-local story storage
- Newsletter demo

Important: this is a front-end prototype. For a real public website, submissions need a server/database and moderation workflow:
Write -> Submit -> Review -> Publish -> Permanent.
